Pill button, mono caps with wide tracking. `variant="primary"` is the inverse pill (primary text colour on the page colour, turns accent on hover) and is THE call to action; use one per view. `secondary` is the outlined pill for the alternative action. `text` is an underlined inline action. Pass `to` for in-app navigation (needs a Router), `href` for an external link (opens in a new tab) or `onClick` for an action. Add a trailing `<ArrowUpRight />` icon for outward actions.
